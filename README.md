# 루나소프트 사내홈페이지 · 라판 전적검색 · 검색엔진 (촬영용 소품 화면)

〈쩔해주세요〉 촬영용 가짜 사내 그룹웨어 화면 + 라스트 판타지아 커뮤니티 전적검색 사이트(S#14) + 가상 검색엔진 NEXO(오승혁 인물정보). 화면 설정(셋업)을 서버(Upstash Redis)에 이름별로 저장해 여러 PC에서 공유합니다.

## 배포 (GitHub → Vercel)

1. 이 폴더를 GitHub 저장소에 올린다.
2. [vercel.com](https://vercel.com) → **Add New… → Project** → 저장소 선택 → 설정 그대로 **Deploy**.
3. 배포된 프로젝트 → **Storage** 탭 → **Create Database** → **Upstash for Redis** (무료 플랜) → 만들고 이 프로젝트에 **Connect**.
   - 연결하면 환경변수(`KV_REST_API_URL`, `KV_REST_API_TOKEN` 등)가 자동으로 들어갑니다.
4. **Deployments** 탭 → 최신 배포 → **⋯ → Redeploy** (환경변수 반영).
5. 배포 주소(`https://프로젝트명.vercel.app`)로 접속. `S` 키 → 설정 메뉴 상단 상태가 초록색 「서버 연결됨」이면 완료.

3번을 건너뛰면 화면은 정상 동작하지만 셋업이 그 PC 브라우저에만 저장됩니다(메뉴에 노란 글씨로 표시).

## 사용

- 특정 셋업으로 바로 열기: `https://프로젝트명.vercel.app/?setup=셋업이름`
- 단축키: `H` 안내 표시, `S` 설정 메뉴, `F`/`T` 자동 입력, `Enter` 등록/검색, `C` 댓글 폭주, `P` 인사발령 팝업, `M` 메신저 알림, `1/2/3` 사내홈페이지 화면, `4/5` 라판 전적검색 홈/결과, `6/7` 검색엔진 홈/인물 결과, `R` 초기화
- 설정 메뉴(`S`)는 화면별 탭(사내 홈페이지 / 익명게시판·글 / 인사발령·알림 / 라판 전적검색 / 검색엔진 / 셋업 저장·공유)으로 구성. 탭을 누르면 해당 화면으로 이동
- `E` 또는 설정 메뉴의 「화면에서 직접 수정」: 화면의 글자를 클릭해 바로 고치고, 공지·기사·연관검색어·경력 같은 목록은 항목을 클릭해 편집·추가·삭제·순서 변경. 하단 편집 바에서 셋업 이름을 넣고 「서버에 저장」
- 검색엔진: 「함께 많이 찾는 인물」은 이름·직함·사진 모두 교체 가능. 검색창에 입력하면 자동완성 검색어가 뜨고(설정 「자동완성 검색어」), 방향키·Enter로 선택

## 익명게시판

실제 게시판처럼 동작하며 글·댓글은 서버(Upstash Redis)에 저장돼 모든 PC에서 같은 내용을 봅니다(4초마다 자동 갱신). 서버 미설정 시 각 PC 브라우저에만 저장됩니다.

- 글: 말머리(자유/회사/업무/질문/유머) · 작성 · 수정 · 삭제(비밀번호 또는 작성한 PC) · 조회수 · 추천/비추천 · 공지 고정 · 인기글(추천 20+ 🔥) · 이전글/다음글
- 댓글: 작성 · 답글 · 추천 · 삭제 · BEST 댓글(추천 3+) · 최신순/등록순/추천순 · 글쓴이/익명N 자동 표시
- 목록: 최신/추천/댓글/조회순 · 인기글 · 말머리 필터 · 검색(제목+내용/제목/댓글) · 15개씩 페이지
- 설정 메뉴에서 샘플 글 32개 재생성 / 게시판 비우기 / 등록 직후 자동 댓글 폭주 on·off

## 구조

- `public/index.html` — 화면 전체(로고 내장)
- `api/presets/index.js` — 셋업 목록
- `api/presets/[name].js` — 셋업 저장/불러오기/삭제
- `api/board.js` — 익명게시판 글·댓글 저장
